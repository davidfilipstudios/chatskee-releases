### Install

1. Download `Chatskee-Setup-x.y.z.exe` from the [latest release](https://github.com/davidfilipstudios/chatskee-releases/releases/latest).
2. Run it. While Chatskee is in beta the installer is not code-signed yet, so Windows may show
   "Windows protected your PC" - click **More info**, then **Run anyway**.
3. Enter your channel names, press **Ctrl + Shift + L** to lock it over your game.

Your game needs to run in **borderless / windowed fullscreen** (nothing can draw over exclusive fullscreen).
