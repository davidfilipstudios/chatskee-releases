Questions streamers ask

Is this allowed on Twitch?

Yes. Twitch's simulcasting rules stop you from showing merged chat on your Twitch stream. Their own FAQ says tools that combine chat are fine "for your personal use", and that's what Chatskee is: a private window only you see, hidden from capture by default.

Does it work over fullscreen games?

Use borderless / windowed fullscreen. Windows doesn't let any window draw over exclusive fullscreen. Most modern games already run borderless, with no real performance difference on Windows 10 and 11.

Will it upset anti-cheat?

It shouldn't. Chatskee never touches your game: no injection, no graphics hooks, no drivers, no admin rights. It's a normal always-on-top window, like a Discord popout. It hasn't been tested against every anti-cheat, so if you try it with yours, tell me how it goes.

Can I dock it in OBS, or use it on a dual-PC setup?

It isn't an OBS dock. It's its own floating window, so on a dual-PC setup just run it on the PC you're looking at.

Do I have to log in to anything?

No. Chatskee reads public chat the same way a logged-out viewer would. It never asks for your passwords or stream keys, and it can't post, ban or change anything.

Mac? Facebook?

Windows only for now. Facebook doesn't let small apps read live chat, so it isn't supported.
